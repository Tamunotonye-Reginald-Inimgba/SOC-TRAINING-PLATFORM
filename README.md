# An Open-Source Interactive SOC Training Platform for Non-Technical SME Staff

This repository contains the source code and supporting technical materials for the MSc Cyber Security (Digital Forensics) Individual Research Project, module 7005SCN, Coventry University.

The project develops and evaluates an isolated, open-source Security Operations Centre (SOC) training platform designed to help non-technical small and medium-sized enterprise (SME) staff recognise cyber-attack activity, observe security alerts and receive plain-English explanations of detected events.

## Main Components

- Flask-based no-code attack-scenario launcher
- Eight MITRE ATT&CK-mapped attack scenarios
- Wazuh Security Information and Event Management (SIEM) integration
- Suricata intrusion detection evidence and configuration
- Local LLM explainability service using Ollama
- Alert-validation and evaluation materials
